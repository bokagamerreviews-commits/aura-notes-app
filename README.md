# Aura Notes — Custom 5-Theme Offline Android Notepad (Flutter)

A 100% offline, ad-free custom Android Notepad app built with Flutter featuring:
- **Square Grid Note Cards** with **Long-Press (Hold) Action Sheet** for instant **Pin/Unpin**, **Copy to Clipboard**, **Android Share**, and **Permanent Delete** (no recycle bin).
- **3 Note Types via Right-Side Popup Menu (`+`)**:
  1. **Text Note**: Title + Description with full multilingual (Bangla/English) & system keyboard voice-typing support, Undo/Redo, and real-time auto-save.
  2. **Table Sheet**: Default **10 rows × 3 columns** editable grid with labeled **Add Row**, **Add Column**, **Row -**, and **Col -** buttons.
  3. **To-Do Checklist**: Interactive tasks with auto-sorting completed items and live completion progress badge.
- **5 Built-In Custom UI Themes**:
  1. **Botanical Glassmorphism** (with custom Gallery/SD Card background photo upload).
  2. **Solo Leveling Dark Neon HUD** (with customizable neon glow color).
  3. **Tactile 3D Neumorphism** (with customizable base surface and glowing accent colors).
  4. **Luxury Dual-Mode** (instant switcher between **Beige Sand** and **Imperial Green**).
  5. **Refractive 3D Liquid Glass** (with customizable studio tint and liquid glow colors).
